PashuAahar is an AI-powered livestock management and productivity application designed to empower rural dairy farmers in Karnataka. It bridges traditional farming with modern data-driven agriculture to improve cattle health, reduce costs, and increase profitability.

🚀 Key Features

🤖 Pashu-Maitra AI Assistant
Bilingual support (Kannada & English)
Powered by Google Gemini API
Provides:
Veterinary health advice
Nutrition guidance
Financial insights
Context-aware responses using cow data

🥗 Smart Feed Optimizer
Custom feed calculation engine
Optimizes feed ratio (maize, oil cake, etc.)
Based on:
Breed
Weight
Milk yield
Reduces feed cost and wastage

📊 Financial Dashboards
Milk yield tracking (daily / weekly)
Feed cost monitoring
Profit / Loss analysis
Cost vs Profit comparison graphs
Built using MPAndroidChart

🌍 Bilingual Support
Kannada + English interface
Easy language switching
Designed for rural farmers

📶 Offline Fallback System
Basic veterinary advice without internet
Works in low network areas
Smart fallback logic for common queries

🛠️ Technologies Used
Kotlin (Android Development)
Jetpack Compose + XML (Hybrid UI)
Gemini API (AI Integration)
OkHttp (Networking)
MVVM Architecture
Material Design 3
MPAndroidChart (Graphs)

📉 Problem Statement
Feed cost = 60–70% of dairy expenses
Lack of veterinary access in rural areas
No digital tracking system for farmers
Language barrier in existing solutions

💡 Solution

PashuAahar acts as:

🧠 Digital Veterinary Assistant
📊 Financial Analyst
🥗 Feed Optimization System
